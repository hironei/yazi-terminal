# yazi-desktop-host.yazi

The optional Yazi bridge plugin for Yazi Terminal. It publishes Yazi's current
directory, hovered item, and selection to the host for bridge-backed Shell
targeting and Explorer drag-and-drop behavior.

Install it with Yazi's package manager:

```powershell
ya pkg add hironei/yazi-terminal:yazi-desktop-host
```

See the [Yazi Terminal user manual](https://github.com/hironei/yazi-terminal/blob/main/docs/user-manual.md#plugin-installation)
for configuration and manual installation instructions.
